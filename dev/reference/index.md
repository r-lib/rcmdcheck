# Package index

## Run `R CMD check` programmatically

- [`rcmdcheck()`](https://rcmdcheck.r-lib.org/dev/reference/rcmdcheck.md)
  :

  Run `R CMD check` on a package or a directory

- [`rcmdcheck_process`](https://rcmdcheck.r-lib.org/dev/reference/rcmdcheck_process.md)
  :

  Run an `R CMD check` process in the background

## Query CRAN checks

- [`cran_check_flavours()`](https://rcmdcheck.r-lib.org/dev/reference/cran_check_flavours.md)
  : Download and show all CRAN check flavour platforms
- [`cran_check_results()`](https://rcmdcheck.r-lib.org/dev/reference/cran_check_results.md)
  : Download and parse R CMD check results from CRAN
- [`check_details()`](https://rcmdcheck.r-lib.org/dev/reference/check_details.md)
  : Query R CMD check results and parameters
- [`print(`*`<rcmdcheck>`*`)`](https://rcmdcheck.r-lib.org/dev/reference/print.rcmdcheck.md)
  : Print R CMD check results
- [`xopen(`*`<rcmdcheck>`*`)`](https://rcmdcheck.r-lib.org/dev/reference/xopen.rcmdcheck.md)
  : Open the check directory in a file browser window

## Parse check results

- [`parse_check()`](https://rcmdcheck.r-lib.org/dev/reference/parse_check.md)
  :

  Parse `R CMD check` results from a file or string

- [`parse_check_url()`](https://rcmdcheck.r-lib.org/dev/reference/parse_check_url.md)
  : Shorthand to parse R CMD check results from a URL

## Compare check results

- [`compare_checks()`](https://rcmdcheck.r-lib.org/dev/reference/compare_checks.md)
  : Compare a set of check results to another check result
- [`compare_to_cran()`](https://rcmdcheck.r-lib.org/dev/reference/compare_to_cran.md)
  : Compare a check result to CRAN check results
- [`print(`*`<rcmdcheck_comparison>`*`)`](https://rcmdcheck.r-lib.org/dev/reference/print.rcmdcheck_comparison.md)
  : Print R CMD check result comparisons
